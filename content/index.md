# Aevus's Solo TTRPG Actual Plays!

While I've been a long-time player of first D&D 5e, and nowadays Pathfinder 2e, I've only just recently began delving into the world of Solo tabletop roleplay. I've also been wanting to find ways to be more active on my website, so I thought, why not say fuck it and share my writings? Maybe other people will enjoy reading my campaigns just as much as I love playing them :3

## Guide

This is a project I've only *just* begun, so there isn't a whole lot to see yet. Case and point, I've only had Session 0 of my first solo campaign. The name is still up in the air, but it's a science-fantasy cyberpunk-y setting played in my hacked and mish-mashed style of playing the Ironsworn: Starforged system. If that kinda thing sounds up your alley, you can find Session 0 - Prologue under the "Adventure" folder! And, if you wanna learn a bit about the world my campaign takes place in, you can find info about that in the "Setting" folder.
